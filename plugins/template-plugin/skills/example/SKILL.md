# Example Skill

This skill file is a template for a plugin-owned capability.

## What this skill does

- Explains the plugin's purpose
- Shows how to structure a skill description
- Serves as a copy-ready starting point for new skills

## Example prompts

- "What does this plugin do?"
- "Show me how to use the example workflow."
- "Help me adapt this skill to my own integration."

## Implementation notes

- Keep the heading and summary brief and action-oriented.
- Document inputs, outputs, constraints, and safety considerations.
- Prefer explicit tool and command descriptions over vague prose.
