# Example Agent

Use this file as a pattern for plugin-owned agents.

## Responsibilities

- Gather context
- Execute targeted workflow steps
- Summarize the outcome for the user

## Safety guidance

- Verify tool parameters before invoking destructive actions.
- Confirm high-impact actions with the user when appropriate.
- Keep outputs concise and actionable.
